We’ve made Unistyles incredibly easy to use. You no longer need the `useStyles` hook or wrap your app in React Provider. Unistyles integrates seamlessly with your existing code, so you can start using it immediately.

### Prerequisites

Unistyles 3.0 is tightly integrated with `Fabric` and the latest versions of React Native. Therefore, you must use the **New Architecture** and at least **React Native 0.85.0**. Additionally, Unistyles relies on `react-native-nitro-modules`.

<Aside>Learn more about how Unistyles leverages Nitro Modules [here](/v3/other/dependencies).</Aside>

**Table of requirements:**
|                    | Required                  | Note                        |
|--------------------|---------------------------|-----------------------------|
| React Native       | 0.85.0+                   |                             |
| React              | 19.0.0+                   |                             |
| New Architecture   | enabled                   | no option to opt-out        |
| Expo SDK           | 56+                       | (if you use Expo)           |
| Xcode              | 16.4+                     | Required by Nitro Modules   |
| Platform           | iOS / Android / Web / SSR | Follow instructions below |

Since Unistyles relies on `Fabric`, it cannot run on the `Old Architecture` or older versions of React Native. If you can’t meet these requirements, you can use Unistyles 2.0+, which is compatible with those versions.

### Installation

```shell title="Install Unistyles and its dependencies"
yarn add react-native-unistyles react-native-nitro-modules@0.37.1
```

:::caution
To avoid unexpected behaviors always use a fixed version of `react-native-nitro-modules`.
Check compatibility table [here](https://github.com/jpudysz/react-native-unistyles?tab=readme-ov-file#installation).
:::

<Aside title="Enable edge-to-edge on Android">
We **strongly recommend** setting `edgeToEdgeEnabled=true` in your `android/gradle.properties` — it enforces translucent system bars on modals, disables legacy StatusBar hacks, and enables additional React Native core fixes.

- **Expo SDK 54+**: Already enabled automatically
- **Bare React Native**: Add `edgeToEdgeEnabled=true` to `android/gradle.properties`

You don't need `react-native-edge-to-edge` — the library is deprecated in favor of this built-in property. Learn more [here](/v3/other/dependencies).
</Aside>

### Set up your bundler

Unistyles plugs into your bundler, so it can swap React Native components and track the dependencies of your StyleSheets. Pick the integration for your bundler:

<Tabs>
  <TabItem label="Metro">
    Expo and bare React Native apps use Metro. Wrap your Metro config with `withUnistylesConfig`:

    ```js title="metro.config.js"
    const { getDefaultConfig } = require('expo/metro-config')
    // or for bare React Native
    // const { getDefaultConfig } = require('@react-native/metro-config')
    const { withUnistylesConfig } = require('react-native-unistyles/metro')

    const config = getDefaultConfig(__dirname)

    module.exports = withUnistylesConfig(config)
    ```

    No `metro.config.js` in your Expo app? Create it with `npx expo customize metro.config.js`. Learn more about the [Metro integration](/v3/other/metro).
  </TabItem>
  <TabItem label="Re.Pack, Rspack, Rsbuild">
    Add the experimental `UnistylesPlugin` to the plugins of your Rspack config:

    ```js title="rspack.config.mjs"
    import * as Repack from '@callstack/repack'
    import { UnistylesPlugin } from 'react-native-unistyles/repack-plugin'

    export default {
        // other config
        plugins: [
            new Repack.RepackPlugin(),
            new UnistylesPlugin()
        ]
    }
    ```

    For Rsbuild and Rspack on the web, check the [Re.Pack, Rspack and Rsbuild](/v3/other/repack) guide.
  </TabItem>
  <TabItem label="Other bundlers">
    Next.js, Vite, webpack and other bundlers don't have an integration yet. Use the [Babel plugin](/v3/other/babel-plugin), it's deprecated since Unistyles 3.9.0, but keeps working in 3.x:

    ```js title="babel.config.js"
    module.exports = function (api) {
      api.cache(true)

      return {
        // other config
        plugins: [
            // other plugins
            ['react-native-unistyles/plugin', {
                // pass root folder of your application
                // all files under this folder will be processed by the Babel plugin
                root: 'src'
            }]
        ]
      }
    }
    ```

    Check the Babel plugin [options](/v3/other/babel-plugin#extra-configuration).
  </TabItem>
</Tabs>

<Aside>
Use the styles returned by `useVariants`: `const variantStyles = styles.useVariants({ size })`. The integrations don't change `styles`, see [Variants](/v3/references/variants#selecting-variants).
</Aside>

<Aside type="caution" title="Babel plugin is deprecated">
`react-native-unistyles/plugin` is deprecated since Unistyles 3.9.0 and will be removed in 4.0. Moving from the Babel plugin? Check [Migrating from the Babel plugin](/v3/other/metro#migrating-from-the-babel-plugin).
</Aside>

Finish installation based on your platform:

### As easy as React Native StyleSheet

Getting started with Unistyles couldn’t be easier. Simply replace React Native’s `StyleSheet` with the `StyleSheet` exported from Unistyles. From that moment, you’ll be using a `StyleSheet` with superpowers 🦸🏼‍♂️.

```diff lang="tsx" title="Example.tsx"
- import { StyleSheet } from 'react-native'
+ import { StyleSheet } from 'react-native-unistyles'

const MyComponent = () => {
  return (
    <View style={styles.container}>
      <Text>Hello world from Unistyles</Text>
    </View>
  )
}

const styles = StyleSheet.create({
   container: {
     backgroundColor: 'red'
   }
})
```

By replacing `StyleSheet`, you immediately gain several benefits that aren’t available in React Native’s `StyleSheet`:

- [Variants](/v3/references/variants)
- [Compound variants](/v3/references/compound-variants)
- [Dynamic functions](/v3/references/dynamic-functions)
- [Media queries](/v3/references/media-queries)
- [Horizontal and vertical breakpoints for Native](/v3/references/breakpoints#built-in-breakpoints-landscape-and-portrait)
- [Custom web styles](/v3/references/web-styles)
- [Web only features](/v3/references/web-only)

When you're ready to customize your styles and unlock additional features you can [configure](/v3/start/configuration) Unistyles.
