The Unistyles Babel plugin rewrites supported React Native components to deep imports such as `react-native-unistyles/components/native/View`.
Vite scans dependencies before Babel performs those rewrites, so it cannot discover the generated imports on its own.

The Unistyles Vite plugin declares those imports in `optimizeDeps` for every Vite environment, including client, SSR, and custom environments.

<Aside type="caution" title="The Babel plugin is still required">
The Vite plugin complements the [Unistyles Babel plugin](/v3/other/babel-plugin). It does not transform your source code or replace the Babel plugin.
</Aside>

### Configuration

Unistyles supports Vite 6, 7, and 8. Add the plugin to your Vite config:

```ts title="vite.config.ts"
import { unistyles } from 'react-native-unistyles/vite'
import { defineConfig } from 'vite'

export default defineConfig({
    plugins: [unistyles()]
})
```

No options are required. The plugin uses the same native component list as the Babel plugin, so newly supported components remain in sync.

### Production builds

`optimizeDeps` controls Vite's dependency pre-bundling during development. Adding the plugin does not add the full native component list to your production bundle; the production build still includes only modules reached by your application imports.
